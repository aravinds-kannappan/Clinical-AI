\section{Reproducibility and implementation checks}
The public repository contains locked Python dependencies, exact data manifests, patient-level split assignments, fitted model outputs, frozen prediction arrays, tuning records and all result tables. The main full-release run used commit \texttt{fbfaff0d}; the frozen-policy audit used \texttt{652de9e8}. Exact source archives preserve both computations. The publication entry point runs a fresh full-data evaluation and then the policy audit, rather than requiring the original partial-run resume.

The main evaluation ran on an Apple M4 CPU with 16 GiB memory and two numerical-library/torch threads. The completed full-data run took 9 minutes 3 seconds. It reused a completed logistic seed-11 fit from a 2 minute 40 second partial run that failed during constant-feature binning for boosting. Hashes verify the reused outputs. The later policy audit took 1 minute 20 seconds and did not retrain predictors. Peak memory was not instrumented. Earlier exploratory studies are archived separately and are not included in these run times.

The corrected reviewer audit changes the false-action eligibility rule: a patient with any positive label is not treated as a true negative merely because the patient is ineligible for the strict incident endpoint. The original queue output is retained for provenance and labeled superseded. Predictor scores, incident-loss calculations and calibration-certificate outcomes are unchanged by that correction.

Twenty-three implementation checks pass. These include causal feature invariance, consent/purpose masks, cache revocation, review-path equivalence, the first-alert non-monotonicity counterexample, exact binomial boundary cases, the distinction between infeasibility and insufficient evidence, agreement with official utility, handling of constant/all-missing features and false-action eligibility. These checks are mechanised evidence about the implementation. The proofs in the appendix establish the mathematical results independently of those tests.

The primary public data retain their CC BY 4.0 license and the official evaluator retains its BSD license. No access-controlled dataset agreement is accepted by the code. No new patient or clinician recruitment occurred. This draft does not assert a project-specific institutional approval or exemption; applicable institutional requirements should be resolved before submission or any prospective study.

AI assistance was used in implementation, mathematical drafting, analysis and manuscript preparation. No LLM is used as a predictor or reviewer in the evaluated pipeline. Author responsibility includes checking the mathematical arguments, source attributions and interpretation before submission.
